Aplicação de console interativa desenvolvida em **C# / .NET** para gerenciamento e cadastro de produtos em memória, aplicando conceitos fundamentais de lógica de programação e Orientação a Objetos.

O que o programa faz:
- Adiciona produtos (Nome, Preço, Quantidade)
- Lista todos os produtos
- Busca produto por nome
- Edita dados de um produto
- Remove produto da lista
